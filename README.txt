نسخه جدید Animal News با تقویم رزرو زنده

1) ابتدا calendar-migration.sql را یک‌بار در Supabase > SQL Editor اجرا کنید.
2) در GitHub مخزن ad-booking فایل index.html را با فایل جدید جایگزین کنید.
3) admin.html را نیز نگه دارید/جایگزین کنید.
4) پس از Commit چند دقیقه برای انتشار GitHub Pages صبر کنید.

تقویم شمسی است و امروز تا ۷ روز بعد (۸ روز با احتساب امروز) را نشان می‌دهد. هر روز فقط یک رزرو pending یا approved می‌پذیرد. pending و approved برای دیگران بسته‌اند؛ رد سفارش روز را آزاد می‌کند. تقویم هر ۱۵ ثانیه تازه می‌شود.
